# MLB Relational Database Project ⚾

This project is a complete relational database system designed to model and manage data for **Major League Baseball (MLB)**.

## 📁 Contents

- `Final Report.pdf` – Full project report including:
  - Project motivation and use case
  - Business rules & user requirements
  - Enhanced ER diagram
  - Relations in 3rd Normal Form (3NF)
  - SQL table structure & sample data
  - Queries with joins and aggregates
  - DESC/SELECT screenshots for validation

- `MLB_Project_FullSection5.sql` – SQL script file containing:
  - Full `CREATE TABLE` statements
  - `INSERT INTO` statements for:
    - All 26-man Opening Day rosters (Blue Jays & Yankees)
    - Managers and coaches
    - Teams, contracts, seasons, and games
    - Player performance stats (PlayerStats)
  - Relationships enforced via foreign keys

## 🛠 Technologies Used

- **MySQL Workbench** for schema design and data manipulation  
- SQL DDL & DML commands  
- Entity-Relationship Diagram 

## 📊 Features

- Comprehensive data model of professional baseball operations  
- Realistic interactions: players, teams, contracts, games, performance  
- Sample queries demonstrate:
  - Filtering, sorting, joins  
  - Aggregates like `SUM`, `COUNT`, `AVG`  
  - Real-world use cases (e.g., top hitters, game summaries)

## ✅ Sample Queries Included

- Show all Blue Jays players with contract info  
- List total RBIs per player  
- Average salary per team  
- Matchups between Blue Jays and Yankees  
- Players with home runs in a game  
...and more!

## 📌 Project Goals

- Learn relational modeling and normalization  
- Practice SQL database design and querying  
- Simulate data systems used in real-world sports analytics
